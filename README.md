# Resume / Candidate Screening System

## Project Overview
This project uses NLP and Machine Learning to automatically screen and rank resumes based on job descriptions.

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Jupyter Notebook

## Features
- Resume Text Cleaning
- Skill Extraction
- Resume Ranking
- Job Description Matching
- Similarity Scoring

## Business Insights
- Helps recruiters shortlist candidates faster
- Reduces manual screening effort
- Improves hiring efficiency
